# **App Name**: Video Grabber

## Core Features:

- URL Parsing: Accept a video URL from the user and prepare for download.
- Quality Selection: Allow the user to select the desired video quality (resolution) from available options.
- Download Manager: Manage and execute the video download, saving it directly to the device's gallery.
- Automated Format Recognition: The system will intelligently determine which download tool should be used for the provided link.

## Style Guidelines:

- Primary color: A vivid blue (#29ABE2) to represent digital content and connectivity.
- Background color: A light gray (#F2F4F7) to ensure clarity and focus on video content.
- Accent color: A bright orange (#FF9933) for highlighting download options and interactive elements.
- Body and headline font: 'Inter', a sans-serif font for a modern, readable, and neutral aesthetic.
- Use clear and recognizable icons for actions like 'download,' 'quality selection,' and 'save to gallery.'
- A simple, intuitive layout with a prominent URL input field and clear download options.
- Smooth progress animations during the download process to provide user feedback.
